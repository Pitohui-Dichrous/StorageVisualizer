主要修改

1. 从原 PowerShell + Windows Forms 程序迁移为 C# + Windows Forms，保留框架与逻辑大小口径。
   迁移用于直接编译单文件 GUI，移除 PowerShell 启动、控制台和日志重定向。
2. 使用 Unicode Win32 目录枚举和显式栈，避免深目录递归溢出，支持长路径与 64 位大小。
   后台扫描、节流进度、明确错误与跳过项；取消保留上次完整结果，关闭不留隐藏进程。
3. 完整简体中文，统一系统中文字体、键盘操作与高 DPI 布局，删除原有引导/说明小字。
4. 新增统一蓝色比例条、可展开的排行、按原始数值排序、缓存目录导航和真实系统磁盘容量。
5. 新增树图，稳定调色、面积比例、小项汇总、悬停、鼠标/键盘与无障碍选择。
6. 保留多路径/全部固定磁盘扫描、资源管理器定位、CSV 导出；新增复制路径和返回。
   原版把直接文件合并成一行；新版逐文件显示，总字节数保持一致。
   CSV 为中文列，按当前目录导出；原版每行 Errors 列由根级「详情」窗口取代。
7. 原创文件夹+统计图标，SVG 源和 16–256 像素 ICO；图标及清单内嵌 EXE。
8. 发布程序不写持久配置/缓存/日志，不注册、不联网、不解压运行库；仅显式导出写文件。
9. 提供内置编译器构建脚本、原版逐字节备份、可复现扫描/兼容/树图/便携性测试。
