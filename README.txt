磁盘空间分析器 1.0

运行
双击 dist\磁盘空间分析器.exe。分享或搬到其他位置时，只需这一个文件。
适用于 Windows 10/11（.NET Framework 4.8，较新系统通常已内置）。
不需要 Python、Node、安装程序、联网或管理员权限。程序不释放临时运行库。

使用
输入路径，或点文件夹图标 /「磁盘」，再点「扫描」。
多个目录用分号分隔；路径本身含分号时用双引号包住。
排行默认按原始字节数降序。点列标题排序，点名称前箭头展开，双击文件夹进入。
占比始终相对于当前查看目录；展开的子行仍使用同一分母，不可将父子行再次相加。
树图与排行使用同一份扫描数据。小项过多时合并为「其他」，零字节项只在排行显示。
「返回」图标 / Alt+↑ 返回上级；F5 重新扫描；Esc 取消；Ctrl+L 编辑路径。
「复制」图标复制所选项目路径，未选择时复制当前目录；Ctrl+C 也可使用。
「打开」在资源管理器定位项目；「导出」把当前目录的直接子项写入指定 CSV。
导出必须手动指定保存路径；已有同名文件不会被覆盖。错误/跳过项见「详情」。
取消不会把部分结果当作完成，保留上一次完整结果。关闭窗口即退出，无后台服务。

便携与移除
程序自身不写配置、日志、注册表、自启动项或缓存，不保存扫描历史，不进行联网通信。
扫描只读取目录元数据，不读取文件内容、不删除或修改扫描对象。
只有主动导出的 CSV 会写入你选择的位置；需要时自行保留或删除。
关闭程序后，把 EXE 拖进回收站即可移除程序，无须卸载或清理 AppData。
Windows 自己管理的图标缓存、运行/安全记录和回收站记录不受程序控制，不能保证取证意义的零痕迹。

统计口径与限制
统计逻辑文件长度（1024 进制单位），与原版口径一致，并非磁盘实际分配空间。
压缩、稀疏文件、硬链接、系统保留空间等会使扫描合计与资源管理器磁盘已用值不同。
硬链接按每个目录项计数；所有重解析点（含符号链接、联接和部分云盘占位文件）均跳过。
文件/目录数不含被跳过的重解析点；目录数不含当前查看目录自身。
扫描不是文件系统快照；同时变化或无权限的内容可能使结果不完整，详情最多保留前 100 条。
多个输入目录有重叠时分别统计，合计会重复包含重叠内容。
磁盘容量来自系统报告的总容量与当前用户可用容量，配额会影响数值；网络/无法查询时显示不可用。
磁盘状态：低于 80% 正常；80% 至不足 90% 偏紧；90% 以上紧张。此颜色不用于文件夹排名。
扫描支持 Unicode 和长路径；资源管理器打开和 CSV 保存仍受相应系统接口的路径限制。
完整目录树保存在内存，超大目录会增加内存使用。遇到慢速网络路径，取消需等待当前系统调用返回；关闭可直接退出。
完整窗口已在本机 125% DPI 实测，树图绘制在 100%/150%/200% 验证；未在其他实体显示器或干净系统实测。
未进行数字签名，未验证 Windows ARM；未在未安装开发工具的独立干净系统实测。

构建与测试
双击 build.cmd（构建时有终端窗口），或执行 powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1。
使用 Windows 内置 .NET Framework C# 编译器；构建不下载依赖。输出仅 dist\磁盘空间分析器.exe。
src 是完整源码；assets 是原创 SVG、ICO、应用清单与许可说明。
tests\run-tests.ps1：扫描正确性测试。
tests\run-compatibility-tests.ps1：实际运行原版函数并与新版对照。
tests\run-treemap-tests.ps1：树图布局、比例、键盘和无障碍测试。
tests\run-portability-tests.ps1：隔离目录中的退出及文件写入检查；加 -ScanSystemDrive 检查扫描中关闭。
测试脚本的报告文件是开发验证产物，正式 EXE 不生成这些文件。
docs\TEST_RESULTS.txt 是本次实测记录；docs 中还保留构建审计和便携性检查数据。
baseline\original.zip 和 baseline\original 是未经修改的原版备份。
