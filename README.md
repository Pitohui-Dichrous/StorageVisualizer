# 储存可视化

<img src="assets/readme.jpg" width="300" alt="好模型">

看看谁把硬盘吃胖了。

**[⬇ 下载 EXE（约 98 KB）](https://github.com/Pitohui-Dichrous/StorageVisualizer/releases/latest/download/StorageVisualizer.exe)**

下载，双击，选个文件夹，扫描。不想用了？关掉删掉，就这么简单。

- 文件夹排行 + 树图，找出空间大户。
- 绿色免安装，不联网，不保存自己的缓存、配置或日志。
- 只看占用，不动你的文件。

Windows 10 / 11，系统需有 .NET Framework 4.8。

想自己编译就双击 `build.cmd`。[详细说明](README.txt)
